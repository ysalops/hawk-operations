# Hawk Operations

Sistema de gestão e acompanhamento operacional de frota desenvolvido para automatizar o processo de geração do panorama diário da operação.

## Objetivo

Centralizar e automatizar informações relacionadas a:

- Frota de veículos
- Motoristas
- Rotas
- Manutenções
- Folgas e indisponibilidades
- Operação diária
- Geração do panorama operacional

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite
- Playwright
